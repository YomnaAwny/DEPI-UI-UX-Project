# DEPI-UI-UX-Project "ع الداير"

Project name: "ع الداير"    
  
Project idea: We aim to minimize agricultural waste by linking sellers who have fruits or vegetables that are about to go to waste with buyers who can use them to produce a long-lasting item on the shelf, such as juices, jam, etc.
